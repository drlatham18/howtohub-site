# HowToHub site

Static landing and privacy pages for the YouTube How-To Factory. GitHub Pages
hosts the site; publishing jobs and scheduled analytics remain on Body 1.
Mac copies are for backup and editing. The production tool requires Windows
DPAPI credentials; dry-run and shadow modes only produce credential-free plans.

The privacy page describes the supported production token-storage behavior.
Update it alongside any future change to credential storage or data handling.
